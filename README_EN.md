# GestorGastos

Personal expense management app, month by month.

## Features

- **Expense registration and editing**: with description, amount, category, date and optional installment payments.
- **Installments**: automatic schedule generation, monthly and per-installment details, editing and deletion.
- **Categories**: full management (create, edit, delete) with customizable color and per-category details.
- **Monthly summary**: dashboard with total expenses, total income and monthly balance.
- **Search**: find expenses by description, category, month, etc.
- **Statistics**: analysis and visualization of the expense history.
- **Monthly income**: record income for each month.
- **Export to Excel**: generates an `.xlsx` file with the monthly breakdown of expenses and income.
- **Import from Excel**: reads `.xlsx` files (generated by the app or by Excel/LibreOffice) and loads them as expenses and income:
  - An expense is identified by having an **amount greater than 0**.
  - If description, category or date is missing, they are filled with defaults (`-`, `-`, first day of the current month); the `-` category is created automatically if it doesn't exist.
- **Multilanguage**: interface in Spanish, English and French.
- **Theme**: modern interface with Material 3 and dark theme.

## Technologies

- **Kotlin**: 2.3
- **Compose Multiplatform**: 1.10 (Material 3)
- **Koin**: dependency injection
- **Decompose**: navigation and architecture
- **SQLDelight**: typed SQLite database
- **kotlinx-serialization**: JSON serialization
- Own `.xlsx` generation and reading (no external Excel dependencies)

## Requirements

- JDK 17+
- Android SDK 36 (to build the Android version)

## Build and run

### Android app (installation)

The app is distributed as a signed APK installer, available in the **Releases** section of the
[repository](https://github.com/NicoAntu/GestorGastos/releases).

1. Download the APK file from the latest release.
2. If the system asks for it, allow installation from unknown sources.
3. Complete the installation wizard and open the app.

### Desktop app (JVM)

```shell
# Windows
.\gradlew.bat :composeApp:run

# macOS/Linux
./gradlew :composeApp:run
```

### Tests

```shell
.\gradlew.bat :composeApp:jvmTest
```
